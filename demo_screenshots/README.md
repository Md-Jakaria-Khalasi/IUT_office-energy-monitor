# Demo Screenshots

The four PNGs in this folder are referenced from the project root
[`README.md`](../README.md). They are **labelled placeholders** generated so
the badge paths resolve; replace each one with a real capture before
publishing.

| File | What to capture |
| --- | --- |
| `dashboard.png` | The Flutter Web overview: header, room cards, live sparkline, activity feed. |
| `alerts.png` | The active-alerts panel with at least one warning/critical alert. |
| `discord_bot.png` | A Discord channel showing the bot's embeds for `!status`, `!room`, or `!usage`. |
| `live_graph.png` | A zoomed-in shot of the live power-by-room graph during a working hour. |

To regenerate the placeholders, run the helper snippet in
`docs/architecture/README.md` (see "Placeholder generation"), or open this
folder in any image editor and overwrite each file.
